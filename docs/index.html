Rotor Testbench

Welcome to the Rotor Testbench web docs.

THE PROJECT

A test bench for brushless motors and rotors. An Arduino Nano drives the ESC and protects the hardware (lock, button, battery checks, heartbeat, watchdog). A Raspberry Pi is the server: it talks to the Nano over USB and manages the tests. In the future, a dashboard in the browser will create and run tests and show the data.
